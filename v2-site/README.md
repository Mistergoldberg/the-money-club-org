# The Money Club V2

This is the isolated Astro application for The Money Club V2.

The production site remains in the sibling `new site/` directory and is treated as
frozen. V2 must not import, symlink, or depend on files from that directory.

## Current Scope

Phase 1 and Phase 2 preparation only:

- Design tokens and global CSS foundations
- Central route, program, and SEO data
- Base layout and accessible responsive navigation
- Shared UI, form, and conversion primitives
- Internal `/foundation-preview` route for validation

Full homepage and funnel page production has intentionally not started.

## Commands

```sh
npm install
npm run check
npm run build
npm run dev
```
